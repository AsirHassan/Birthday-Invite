RSVP
This version uses WhatsApp instead of a database.

IMPORTANT:
Open index.html and find:
const HOST_WHATSAPP = "352XXXXXXXX";

Replace 352XXXXXXXX with the birthday parent's WhatsApp number in international format, without +, spaces or dashes.

Example:
const HOST_WHATSAPP = "352621123456";

Guests then tap:
- I'M COMING
- CAN'T MAKE IT

WhatsApp opens with a pre-written RSVP. For "I'm coming", they add the names and total number of guests and send it.

The page also has a Google Maps button using the supplied coordinates.

MUSIC
The page uses f1-theme.mp3 as its looping soundtrack.

It attempts audible autoplay immediately when the link opens, with a smooth
fade-in and a comfortable default volume. Some mobile browsers and WhatsApp's
in-app browser prohibit audible autoplay by browser policy; when that happens,
the page shows a clear PLAY prompt and starts audio on the first tap anywhere
on the page (or on the sound control).

MOBILE MEDIA
The original yahya-f1.png is kept as the source image. The page serves:
- yahya-f1.jpg on larger screens
- yahya-f1-mobile.jpg on phones

This cuts the main photo download substantially while keeping the image sharp.
